**Unraid ZFS Snapshot Manager 0.5.1**

Wird unter den Einstellungen ein- oder ausgeschaltet. Die eigentliche Verwaltung liegt im Hauptreiter `Snapshots`. Zeigt den Unraid-Array-Zustand, ZFS-Datasets und Snapshots an und erstellt manuelle Snapshots. Pro Dataset kann eine stündliche, tägliche oder wöchentliche automatische Regel mit altersbasierter Aufbewahrung eingerichtet werden. Nur eindeutig der Regel zugeordnete automatische Snapshots werden bereinigt. Eigene Plugin-Snapshots verwenden eine einfache Sicherheitsabfrage. Für fremde Snapshots muss vor dem Löschen der vollständige Name eingegeben werden. Snapshots mit Klonen oder ZFS-Holds werden nicht gelöscht. Rollback ist nicht enthalten.
