**Unraid ZFS Snapshot Manager 0.3.0**

Wird unter den Einstellungen ein- oder ausgeschaltet. Die eigentliche Verwaltung liegt im Hauptreiter `Snapshots`. Zeigt den Unraid-Array-Zustand, ZFS-Datasets und Snapshots an, erstellt manuelle Snapshots und löscht ausschließlich eindeutig gekennzeichnete manuelle Plugin-Snapshots. Snapshots mit Klonen oder ZFS-Holds werden nicht gelöscht. Diese frühe Testversion enthält keine Retention- oder Rollback-Funktion.
