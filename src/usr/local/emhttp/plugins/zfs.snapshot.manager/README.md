**Unraid ZFS Snapshot Manager 0.4.0**

Wird unter den Einstellungen ein- oder ausgeschaltet. Die eigentliche Verwaltung liegt im Hauptreiter `Snapshots`. Zeigt den Unraid-Array-Zustand, ZFS-Datasets und Snapshots an und erstellt manuelle Snapshots. Eigene Plugin-Snapshots verwenden eine einfache Sicherheitsabfrage. Für fremde Snapshots muss vor dem Löschen der vollständige Name eingegeben werden. Snapshots mit Klonen oder ZFS-Holds werden nicht gelöscht. Diese frühe Testversion enthält keine Retention- oder Rollback-Funktion.
