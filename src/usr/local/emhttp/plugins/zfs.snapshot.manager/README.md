**Unraid ZFS Snapshot Manager 0.9.0**

Wird unter den Einstellungen ein- oder ausgeschaltet. Die eigentliche Verwaltung liegt im Hauptreiter `Snapshots`. Zeigt den Unraid-Array-Zustand, ZFS-Datasets und Snapshots an und erstellt manuelle Snapshots. Der Tab `Pools & Scrub` zeigt Pool-Zustand, letzten oder laufenden Scrub, reparierte Daten, Fehler und Fortschritt. Scrubs können pro Pool manuell gestartet und abgebrochen werden. Ein monatlicher Auto-Scrub lässt sich über die stabile Pool-GUID aktivieren und wird ohne parallele Scrubs täglich um 03:00 Uhr auf Fälligkeit geprüft. Pro Dataset kann eine stündliche, tägliche oder wöchentliche automatische Regel mit altersbasierter Aufbewahrung eingerichtet werden. Unter-Datasets können optional rekursiv einbezogen werden. Nur eindeutig der Regel zugeordnete automatische Snapshots werden bereinigt. Eigene Plugin-Snapshots verwenden eine einfache Sicherheitsabfrage. Fremde Snapshots lassen sich nach derselben Sicherheitsabfrage löschen. Verwaiste VM-Snapshots werden in der Snapshot-Tabelle gekennzeichnet. Snapshots mit Klonen oder ZFS-Holds werden nicht gelöscht. Pro Dataset kann eine private, schreibgeschützte SMB-Freigabe mit allen Snapshots eingerichtet werden. Rollback und Windows-Vorgängerversionen sind nicht enthalten.
